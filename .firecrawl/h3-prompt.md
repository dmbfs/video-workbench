# H3 Feature Highlights

> A gallery of representative examples showing MiniMax H3's three core capabilities: Native Multimodal Understanding & Generation, Precise Multimodal Editing & Control, and Production-Ready Content Creation Across Use Cases.

For model specs, input constraints, and how to call the API, see [Video Generation](/docs/guides/video-generation).

| Three core capabilities                                                                              | Description                                                                                                                                                                                      |
| :--------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| <span style={{ whiteSpace: 'nowrap' }}>**Native Multimodal Understanding & Generation**</span>       | Accepts text, images, audio, and video as inputs. Understands characters, motion, sound, emotion, camera work, style, and intent, and fuses multiple references into unified audiovisual output. |
| <span style={{ whiteSpace: 'nowrap' }}>**Precise Multimodal Editing & Control**</span>               | Edits characters, objects, scenes, sound, and pacing across multiple dimensions with fine-grained instruction following, so you can iterate on existing content predictably.                     |
| <span style={{ whiteSpace: 'nowrap' }}>**Production-Ready Content Creation Across Use Cases**</span> | Built for film, advertising, branding, e-commerce, and gaming — covers on-screen text, brand assets, creative effects, product showcases, UI/UX motion, game visuals, and stylized expression.   |
